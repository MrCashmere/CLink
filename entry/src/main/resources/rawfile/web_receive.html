传输小提示
  1. 两台设备需连接同一局域网，并保持接收设备上的羊绒互传已打开。
  2. 发送前，请在接收设备上确认本次请求；设置了接收 PIN 时，按提示输入。
  3. 动态照片和 HDR 照片会按接收设备适配，下载的文件名或格式可能有所变化。
  4. 连接失败时，请确认网络可达，然后刷新页面重试。
